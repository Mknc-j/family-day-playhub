How to Play

The system has created a secret access code. Choose characters and submit your guess.

  • Correct position: right character, right place.
  • Wrong position: right character, wrong place.
  • Incorrect: not part of the code, or already counted.

Use the clues to crack the code before your attempts run out. This is a logic game about password strength, not real hacking.
